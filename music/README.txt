SHIMMER MUSIC FOLDER

The six included tracks are already registered in playlist.js and appear in the
"choose the music" selector.

To add another song:
1. Put the MP3/OGG file in this folder.
2. Add one entry to playlist.js, for example:
   { name: "My Song", file: "music/My Song.mp3" },
3. Open index.html again.

While music plays, Shimmer listens to the audio spectrum locally in the browser:
- bass gently pushes the pond's breathing/ripples
- mids influence the soft movement
- highs add extra pearly shimmer and notes
- the cat randomly picks a tiny instrument and reacts with cute animations

No external audio service is used.
